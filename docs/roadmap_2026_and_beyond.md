## 2. Milestone Details

### Milestone 1: Stellar Mainnet Deployment & Drips Wave Integration (Q4 2026)
- Deploy audited Soroban contracts (`bazaar_deal_engine`, `demand_circle_registry`) to **Stellar Mainnet**.
- Seed initial wholesale purchasing circles in hardware, renewable energy equipment, and computing electronics.
- Integrate continuous Drips streaming for community contributor rewards and treasury streaming.

### Milestone 2: Automated RFQ Engine & Oracle Integration (Q1 2027)
- Integrate on-chain price oracles (Reflector Network) to benchmark ceiling prices against live spot commodity rates.
- Deploy open-source Telegram and WhatsApp procurement bots using `@stellar-bazaar/sdk`.
- Launch Merchant Portal for supplier catalog automated quoting.

### Milestone 3: Cross-Chain Liquidity & Bridge Ingestion (Q2 2027)
- Enable multi-chain deposits (USDC on Ethereum / Polygon / Base) bridging seamlessly into Stellar Asset Contract escrow.
- Support automated FX conversion using Stellar Decentralized Exchange (DEX) path payments.

### Milestone 4: Native Mobile Apps & Community DAO Governance (Q3–Q4 2027)
- Release native iOS and Android applications utilizing Passkey WebAuthn signers (zero seed-phrase friction).
- Transition protocol fee parameters and arbitrator whitelists to decentralized token-weighted DAO voting.
